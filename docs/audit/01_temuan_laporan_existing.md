## Hitung ulang independen, database lokal

Sampel memakai batas `timestamptz` Asia/Jakarta setengah terbuka. Query independen mengagregasi order dan payment langsung, tanpa memakai controller. Tanggal 8 November 2026: 1 order, 0 “Sesuai”, 1 payment belum final. Periode 1–30 November 2026: 8 order, 4 “Sesuai”, 4 payment belum final, 0 tanpa payment/referensi hilang/beda `total_amount`. Empat payment berstatus `paid` mempunyai jumlah `paid_amount = 0`, sedangkan detail pembayaran `success` berjumlah Rp68.100 dan sama dengan total empat order. Hasil ini cocok dengan klasifikasi CASE controller **untuk sampel tersebut**, tetapi tidak membuktikan saldo bank atau semua laporan lain.

```sql
SELECT count(*) AS orders,
       count(*) FILTER (WHERE eo.payment_id IS NOT NULL
         AND p.id IS NOT NULL
         AND abs(coalesce(p.total_amount, 0) - coalesce(eo.grand_total, 0)) <= 0.01
         AND p.status::text = 'paid') AS matching_by_current_rule,
       sum(eo.grand_total) FILTER (WHERE p.status::text = 'paid') AS paid_order_total,
       sum(p.paid_amount) FILTER (WHERE p.status::text = 'paid') AS paid_amount_total
FROM ecommerce_orders eo
LEFT JOIN payments p ON p.id = eo.payment_id
WHERE eo.created_at >= timestamptz '2026-11-01 00:00:00+07'
  AND eo.created_at < timestamptz '2026-12-01 00:00:00+07';
```

Query terpisah menjumlahkan `payment_details.amount` berstatus `success` per payment sebelum join ke order, agar detail multipel tidak menggandakan order. Nilai agregat di atas adalah snapshot lokal saat pemeriksaan, bukan angka produksi.

Untuk stok toko, query controller tanpa filter menghasilkan 4 kelompok produk/lokasi dengan total `qty_real = 15`, reservasi 0, dan available 15. Hitung ulang independen atas `store_items JOIN items` menemukan 37 tautan item unik, 15 berstatus `store_stock`/`store_display`, dan 0 item yang juga tertaut ke `warehouse_items`. **Ini hanya memvalidasi total fisik pada snapshot lokal**, belum membuktikan mutasi, cutoff, FEFO, atau seluruh laporan stok. `EXPLAIN` query controller toko memperkirakan cost 125,55; query gudang cost 8418,63 tanpa filter.
