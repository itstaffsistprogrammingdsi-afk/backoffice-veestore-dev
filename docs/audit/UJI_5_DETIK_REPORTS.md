# Uji 5 Detik Halaman Laporan

Status: belum dijalankan. Uji ini membutuhkan 2 pengguna non-teknis dan tidak boleh diisi dengan hasil rekaan.

## Tujuan

Mengukur apakah informasi inti setiap halaman utama dapat dipahami dalam 5 detik tanpa bantuan.

## Halaman yang diuji

1. `/reports/business-overview` Ringkasan Usaha
2. `/reports` Pusat Laporan
3. `/reports/price-margin` Kontrol Margin Harga
4. `/reports/crm` Ringkasan Pelanggan
5. `/reports/supplier-products` Produk Pemasok
6. `/reports/history-customer` Riwayat Pelanggan
7. `/monitoring/payment-reconciliation` Rekonsiliasi Pembayaran

## Langkah

1. Buka halaman pada desktop 1440 px, tampilkan hanya viewport pertama.
2. Tampilkan selama 5 detik, lalu tutup layar.
3. Ajukan pertanyaan berikut tanpa memberi petunjuk.

| Halaman | Pertanyaan |
|---|---|
| Ringkasan Usaha | Angka utama apa yang ditampilkan, dan untuk periode apa? |
| Pusat Laporan | Di mana Anda mencari laporan penjualan dan laporan pelanggan? |
| Kontrol Margin | Produk mana yang perlu diperiksa, dan apa arti angkanya? |
| Ringkasan Pelanggan | Berapa pembeli, transaksi, dan nilai belanja pada periode ini? |
| Produk Pemasok | Berapa nilai stok dan pemasok yang terlibat? |
| Riwayat Pelanggan | Transaksi atau kunjungan apa yang terlihat, dan di kanal mana? |
| Rekonsiliasi Pembayaran | Apakah ada anomali pembayaran, dan berapa banyak? |

## Format catatan

| Peserta | Halaman | Jawaban | Paham (Ya/Tidak) | Waktu |
|---|---|---|---|---|
| P1 |  |  |  |  |
| P2 |  |  |  |  |

## Kriteria lulus

- Kedua peserta menyebut angka atau status kunci dengan benar pada minimal 5 dari 7 halaman.
- Tidak ada peserta yang membutuhkan lebih dari 5 detik untuk menemukan periode data.
- Setiap kebingungan dicatat dan diperbaiki sebelum rilis.
